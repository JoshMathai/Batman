## Customization Options

**Want to add more?**
- Add new detail pages in `/details/` folder
- Add images to sections (use `loading="lazy"`)
- Change colors by updating CSS variables
- Add new sections with scroll animation classes
- Modify animation speeds in CSS keyframes
- Add video content to panels

**Animation Classes to Use:**
- `scroll-fade-in` - Simple fade
- `scroll-slide-in` - Slide from left
- `scroll-pop-in` - Scale with bounce
- `scroll-up` - Slide up with fade
- `scroll-parallax` - Parallax movement
